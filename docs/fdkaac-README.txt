fdkaac for Windows x64 - OPT-IN BUILD, RESTRICTED LICENCE
=========================================================

This zip contains fdkaac.exe, the nu774/fdkaac command-line front end (zlib-style
licence, see COPYING-fdkaac.txt), statically linked with libfdk-aac from
https://github.com/mstorsjo/fdk-aac (Fraunhofer FDK AAC Codec Library for Android).

libfdk-aac is distributed under the "Software License for The Fraunhofer FDK AAC
Codec Library for Android" (full text: NOTICE-libfdk-aac.txt). In short:

  available free of charge (see BUILDINFO.txt for the exact upstream commits; the
  sources are at the URLs above). The library is used unmodified.
* NO PATENT LICENCE is granted. AAC is covered by patents in many countries; using

* The licence is not GPL-compatible, so it must stay a separate program and must
  not be linked into GPL software such as an FFmpeg GPL build.

RenderForge never installs this tool automatically. It is only downloaded when the
user enables fdk-aac in the Encoder Manager and accepts the licence warning.
